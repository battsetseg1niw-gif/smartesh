# SmartESH v73 Activation Code QA
- Replaced user-facing bank receipt workflow with Facebook/email contact + one-time activation code.
- Admin can save contact channels and generate Student/Teacher codes only.
- Redeem is server-side SECURITY DEFINER RPC with auth, role, unused status, expiry and row lock checks.
- Code is single-use and grants/extends Premium by 365 days.
- No password or secret is shared with Admin.
- Existing entitlement UI remains source of Premium status.
- QPay server files are retained for future integration but are not the primary user flow.
