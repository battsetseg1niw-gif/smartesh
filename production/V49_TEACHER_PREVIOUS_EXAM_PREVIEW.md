# SmartESH v49 — Teacher Previous Exam behavior

Teacher:
- Previous Exams is a content source, not a student attempt runner.
- Clicking an available year selects the exam.
- Full test / section actions open Teacher Preview.
- Preview does not save answers, create attempts, or calculate score.
- Teacher can create an assignment Draft from the preview.
- Recipient and deadline are configured in Teacher → Даалгавар.

Student:
- Existing Previous Exam practice/runner behavior remains unchanged.
