# Protected route blueprint

Public:
- landing
- register
- login
- forgot/reset password

Authenticated Student:
- previous exams (published)
- mock/practice
- assignments targeted to self
- own attempts/results/mistakes
- own entitlement

Authenticated Teacher:
- published question bank
- own assignments
- results of assignment targets
- own paper batches
- teacher entitlement

Admin:
- content import/review/publish
- users/access
- payments
- notifications
- settings
- audit logs

Enforce this on the server/database. Client-side menu hiding is only UX.
